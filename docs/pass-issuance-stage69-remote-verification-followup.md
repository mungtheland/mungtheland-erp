# 69단계 남은 원격 독립 검증 체크리스트

모든 항목은 현재 `UNVERIFIED`입니다. 검토자, 시각, 대상 리비전, 비공개 증빙 참조, 판정을 기록합니다. 원시 토큰·시크릿·권한 응답은 보존하지 않습니다. [기존 독립 검증 체크리스트](pass-issuance-stage69-independent-verification-checklist.md)

| 항목 | 검증 주체 | 허용할 증빙 | 필요한 추가 승인 |
| --- | --- | --- | --- |
| 실제 OAuth 클라이언트·계정·범위·파일 허용 이력 | 전용 OAuth 프로젝트 관리자와 요청자 이외의 검토자 | 통제된 설정 또는 허용 이력, 정확한 전용 계정과 앱 및 단일 `drive.file` 검증 결과, 허용 파일 경계와 검토 참조. 운영 리소스에 시험 요청을 보내지 않습니다. | 기존 증빙만으로 부족해 새 OAuth 동의·원격 확인이 필요하면 그 범위를 별도로 승인합니다. |
| 운영 배포 대상과 TEST Script ID 분리 | 권한 있는 운영 관리자와 독립 확인자 | 현재 설정 갱신과 연결되는 승인된 비공개 원본에서 대조한 `DIFFERENT`, `SAME`, `UNVERIFIED` 결과, 리비전·시각·검토자·근거 참조. 실제 시크릿 값과 파생값은 기록하지 않습니다. | 승인된 비공개 증빙에 대한 접근권이 필요합니다. 현재 값의 직접 조회나 Actions 실행은 대조 절차에 포함되지 않습니다. |
| TEST 전용 인증과 보호 정책 | GitHub 환경 관리자와 독립 검토자 | 지정 환경의 브랜치 제한, 관리자 우회 비활성, 독립 필수 검토자·자기 승인 차단, 전용 인증 배치의 비밀값 없는 확인. 이전 보호 환경 증빙에서 필수 검토자와 환경 인증은 미구성이었습니다. | 읽기 확인 권한을 별도로 확보하고, 검토자 설정 또는 인증 배치가 필요하면 각각 변경 승인을 받습니다. |
| 승인 B 이전 사전 스냅샷 및 복구 | 지정 복구 책임자와 다른 독립 확인자 | 전용 TEST 워크북 ID, 시간대와 탭 목록, 고정 탭 충돌 없음, V2·레거시 탭 부재, 16개 헤더 해시, 목표 데이터 행 0건, 복구 책임·중단·읽기 재확인 조건. | 새 사전 읽기를 해야 하면 범위 승인, 실제 초기화는 별도 B. |
| 승인 C 이전 후보와 복구 근거 | TEST 배포 요청자와 독립 배포 검토자, 지정 복구 책임자 | 검토된 정확한 Git SHA, 생성 번들 SHA-256과 파일 인벤토리, 전용 Script ID 대조와 배포 전 소스·매니페스트·설정 복구 기준점. | 새 원격 사전 열람은 범위 승인, 실제 배포는 별도 C 및 보호 환경 요건. 배포 후 실행도 별도로 판단합니다. |

운영 대상 비교나 OAuth 근거가 불완전하면 해당 항목을 `UNVERIFIED`로 남깁니다. 정책 선택만으로 승인이나 게이트 상태를 변경하지 않습니다. [정책 결정](pass-issuance-stage69-conditional-policy-decision.md)
